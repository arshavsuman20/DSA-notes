# 217. Contains Duplicate
## Problem Statement-  
Given an integer array `nums`, return `true` if any value appears at least twice in the array, and return `false` if every element is distinct.  

## Understanding the Problem Statement-  
The problem statement states that: 
1. Integer array `nums` is given,  
2. To Check if any value appears at least twice in array,  
3. Return `true` if any value appears at least (that is >=2) in array,  
4. Return `false` if no value appears at least twice in array.

## 1. Brute Force Approach-  
We check every pair of elements in array and return `true` if any pairs has equal values.   
### Algorithm: 
1. Use 2 nested loops to iterate through array and check all possible pairs of distinct indices.  
2. If any pair has same value, return `true`.  
3. If after checking all pairs, no duplicate is found, return `false`.

### Working with Test Cases:  
Since now we are dealing with the least efficient way of solving the problem, lets have a look at one of the test-cases to solve the problem.  
**Test Case 1**   
Input: `nums[]=[1,2,1,3,4,2] `
Output: `true`  
Explanation:   
We have been given `nums[]` array with values `[1,2,1,3,4,2]`. This array has a length of 6.
`nums[0]=1,  nums[1]=2,  nums[2]=1,  nums[3]=3,  nums[4]=4,  nums[5]=2.  `
According to the algorithm, first we use 2 nested loops for iterating through the entire array.  
When the outer loop is at `nums[0]`, the inner loop will be at `nums[1]`, that is outer loop is initialized to 0 and inner loop is initialized to outer loop+1, and there will be a condition that if these both are equal, we will return `true`. If these two are not equal, we will return `false`.  
### Solution:  
```java
class Duplicate {  
    public boolean containsDuplicate(int[] nums) {  
        for(int outer=0;outer<nums.length-1;outer++){  
            for(int inner=outer+1;inner<nums.length;inner++){  
                if(nums[outer]==nums[inner]) return true;  
            }  
        }  
        return false;  
    }  
}
```
Now this has a Time Complexity of O(n^2) and a Space Complexity of O(1).

## 2)Sorting Approach-  
This is a better approach than Brute Force Approach.   
Here the idea is that we can use the in-built Arrays.sort(array) function to sort the array or manually sort it.  
After sorting, the values which are duplicate will appear next to each other.  
So we can just check the adjacent positions to detect duplicates.  
### Algorithm:
1. Sort array in increasing order  
2. Iterate through array  
3. Compare current element with next element  
4. If both are equal, return `true`  
5. If no duplicates found, return `false`.

### Working with Test Cases:  
Since now we are dealing with the a better way of solving the problem, lets have a look at one of the test-cases to solve the problem.  
**Test Case 1**   
Input: `nums[]=[1,2,1,3,4,2]  `
Output: `true`
Explanation:   
We have been given `nums[]` array with values `[1,2,1,3,4,2]`. This array has a length of 6.  
According to the algorithm, sorting the array in increasing order gives:`[1,1,2,2,3,4].`
So when we compare the current element with next element, in this particular test case, the values are equal, so the code returns `true`.  
### Solution:
```java
import java.util.*;  
class Solution {  
    public boolean containsDuplicate(int[] nums) {  
        Arrays.sort(nums);  
        for(int i=0;i<nums.length-1;i++){  
            if(nums[i]==nums[i+1]){  
                return true;  
            }  
        }  
        return false;  
    }  
}
```
Since, `Arrays.sort(array)` is an in-built function, it uses Quick-Sort, which has Time Complexity of O(n*logn), and a Space complexity of O(1).

## 3)Optimal Approach-  
This is the best way to solve this problem using Hash Set.  
When we iterate through the array, we check whether that value is already present in the set. If there exists a value, that means duplicate exists.  
### Algorithm:
1. Initialize an empty hash set to store the values of array.  
2. Iterate through each value in array.  
3. For each value:  
* If it is already in set, return `true` because duplicate is found.  
* Orelse, add it to the set.  
4. If the loop finishes without finding any duplicates, return `false`.

### Working with Test Cases:  
Since now we are dealing with the the best way of solving the problem, lets have a look at one of the test-cases to solve the problem.
**Test Case 1**   
Input: `nums[]=[1,2,1,3,4,2] `
Output: `true`  
Explanation:  
An empty Set has been initialized and each value of array is iterated.  
The values are added in the set if it is not present there.  
`nums[0]=1` is added in set, `nums[1]=2` is checked and is not equal to `nums[0]` so it is added in the set, `nums[2]=1` is checked and is found to be equal to `nums[0]`, so `true` is returned.  
### Solution:  
```java
import java.util.*;
public class Duplicates{
    public boolean hasDuplicate(int[] nums) {  
            Set<Integer> seen = new HashSet<>();  
            for (int num : nums) { 
                if (seen.contains(num)) {  
                    return true;  
                }  
                seen.add(num);  
            }  
        return false;  
        }
}
```
Now this has a Time complexity of O(n) and a Space complexity of O(n).
