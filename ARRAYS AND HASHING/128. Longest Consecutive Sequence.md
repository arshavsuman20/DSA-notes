# 128. Lonegst Consecutive Sequence

## Problem Statement-

Given an array of integers `nums`, return length of longest consecutive sequence of elements that can be formed.

## Understanding the Problem Statement-

A consecutive sequence is a sequence of elements in which each element is exactly `1` greater than previous element. The elements do not have to be consecutively in original array.

## 1. Sorting Approach-

After sorting, all consecutive numbers will appear side by side in the whole array. This will make it easy to traverse the sorted array and count the longest sequence.  
We move forward if current number matches expected next value in sequence. Duplicates are skipped while gaps reset the streak.

### Algorithm:

1. If array is empty, return `0.`  
2. Sort array in increasing order.  
3. Initialize:  
    * `res` for longest streak,  
    * `curr` as first number,  
    * `Streak` as `0`,  
    * `i=0`  
4. While `i` is within bounds:  
    * If `nums[i]` does not matches `curr`, reset: `curr=nums[i]` and `streak=0`,  
    * Skip duplicates by `nums[i]==curr`  
    * Increase `streak` if we found the expected number,  
    * Update `res` with maximum streak found.  
5. Return `res` after scanning the entire array.

### Working with Test Cases:

Input: `nums = [2, 20, 4, 10, 3, 4, 5]`  
Output: `4`  
Explanation:  
`Arrays.sort` sorts the entire array and gives us: `[2, 3, 4, 4, 5, 10, 20]`  
Iteration 1: `curr==nums[i]`: no reset, in the inner while: `i=1`, after the inner while: `streak=1`,  `curr=3`, `res=1`.  
In iteration 2: `streak=2`, `curr=4`, `res=2`.  
In iteration 3: again condition satisfies and inner while: `i=3` and `i=4` is skipped: `streak=3`, `curr=5`, `res=3`.  
In iteration 4: when inner while’s `i=5`: `streak=4`, `curr=6`, `res=4`.  
In iteration 5: there is a break in sequence, `curr!=nums[i]` so we reset the streak and curr values. `streak=1`, `curr=11`, `res=4`.  
In iteration 6: same as iteration 5, `streak=1`, `curr=21`, `res=4`.  
Loop ends and so `res=4`. The longest consecutive sequence is `[2,3,4,5]`.

### Solution:

```java  
public class Solution {  
    public int longestConsecutive(int[] nums) {  
        if (nums.length == 0) {  
            return 0;  
        }  
        Arrays.sort(nums);  
        int res = 0, curr = nums[0], streak = 0, i = 0;

        while (i < nums.length) {  
            if (curr != nums[i]) {  
                curr = nums[i];  
                streak = 0;  
            }  
            while (i < nums.length && nums[i] == curr) {  
                i++;  
            }  
            streak++;  
            curr++;  
            res = Math.max(res, streak);  
        }  
        return res;  
    }  
}  
```  
Since here we are sorting, so `T(n) = O(nlogn)` and `S(n) = O(1)`.

## 2. Hash Map Approach-

When we place a new number into the map, it may connect two existing sequences or extend one of them.  
Instead of scanning forward or backward, we only look at the lengths stored at the neighbors:  
`mp[num - 1]` gives the length of the sequence ending right before num and  
`mp[num + 1]` gives the length of the sequence starting right after num.  
By adding these together and including the current number, we know the total length of the new merged sequence.  
We then update the left boundary and right boundary of this sequence so the correct length can be retrieved later.  
This keeps the whole operation very efficient and avoids repeated work.

### Algorithm:

1. Create a hash map `mp`, to store sequence lengths at boundary positions.  
2. `res=0` to store longest sequence.  
3. For each `num` in input:  
    * If `num` is in `mp`, skip,  
    * `length = mp[num-1] + mp[num+1] + 1`  
    * Left boundary: `length = mp[num - mp[num-1]]`  
    * Right boundary: `length = mp[num + mp[num+1]]`  
    * Update `res` to keep track of LCS.  
4. Return `res`.

### Working with Test Cases:

Input: `nums = [2, 20, 4, 10, 3, 4, 5]`  
Output: `4`  
Explanation:  
`mp` does not contains `2`, so `left=0`, `right=0`, `len=1`.  
`mp.put(2, 1)`  
`mp.put(2, 1)`   // left boundary  
`mp.put(2, 1)`   // right boundary  
`num=20`: `mp = {2=1, 20=1}`, `res = 1`  
`num=4`: `mp = {2=1, 20=1, 4=1}, res = 1`  
`num=10`: `mp = {2=1, 20=1, 4=1, 10=1}, res = 1`  
`num=3`: connects `2` and `4`. Left boundary is 2 and right is 4.  
`mp = {2=3, 3=3, 4=3, 20=1, 10=1}, res = 3`  
Sequence is formed: `[2,3,4]`  
Skip the duplicates.   
When `num=5`: left boundary is 2 and right is 5.  
So, `mp = {`  
  `2=4,`  
  `3=3,`  
  `4=3,`  
  `5=4,`  
  `10=1,`  
  `20=1`  
`}`  
`res = 4`  
Final sequence is: `[2,3,4,5]`

### Solution:

```java  
public class Solution {  
    public int longestConsecutive(int[] nums) {  
        Map<Integer, Integer> mp = new HashMap<>();  
        int res = 0;

        for (int num : nums) {  
            if (!mp.containsKey(num)) {  
                mp.put(num, mp.getOrDefault(num - 1, 0) + mp.getOrDefault(num + 1, 0) + 1);  
                mp.put(num - mp.getOrDefault(num - 1, 0), mp.get(num));  
                mp.put(num + mp.getOrDefault(num + 1, 0), mp.get(num));  
                res = Math.max(res, mp.get(num));  
            }  
        }  
        return res;  
    }  
}  
```  
We are using maps, so each number in `nums` is processed atmost once and hashmap’s operations are `o(1)` on average so overall `T(n)=O(n)` and `S(n)=O(n)`.
