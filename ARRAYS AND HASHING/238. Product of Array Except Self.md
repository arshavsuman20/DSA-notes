# 238. Product of Array Except Self

## Problem Statement-

Given an integer array `nums`, return an array `output` where `output[i]` is the product of all the elements of `nums` except `nums[i]`.

## Understanding the Problem Statement-

The problem statement states that out of array `nums` give an `output` array where the values of `output[i]` should be the product of values of `nums` except at its index. That is, if I am at the `0th` index of `nums`, then the `0th` index of `output` should contain product of `1st` to `(n-1)th` index.

## 1. Prefix and Suffix Approach-

For each index, we need the product of elements before it and all elements after it. For this, we can compute `prefix[]` and `suffix[]` array, but to optimize space, we do not create an extra `prefix[]` array.  
Instead, we do the `prefix[]` array part in the original array itself. For the `suffix[]` array part, we traverse from the end of array and compute the suffix.  
Hence the final ans would be `prefix[index] * suffix[index]`

### Algorithm:

1. Create an answer array which is initialized with 1.  
2. Compute the prefix products in the original array itself. For each index `i`, store product of all numbers before `i` :  
   `ans[index] = ans[index-1] * nums[index-1]`  
   This means that `ans[index]` contains product of `nums[0]` to `nums[index-1]`.  
3.  Compute the suffix products. For this create a variable `suffix=1`. Traverse array from right to left. Multiply `suffix` into `ans[i]` and keep updating suffix:  
   `suffix = suffix * nums[index+1]`  
   `ans[index] = ans[index] * suffix`  
4. Return the `ans[]` which now stores product of prefix and suffix for each index.

### Working With Test Cases:

**Test Case1:**  
Input: `nums = [1,2,4,6]`

Output: `[48,24,12,8]`

Explanation:

For the prefix pass, update `ans[index]` by product of all elements before index .

| index | ans[i] | ans[] |
| :---- | :---- | :---- |
| start | Initialized as `[1,1,1,]` | `[1,1,1,1]` |
| i=1 | `ans[1] = ans[0]*nums[0]=1*1` | `[1,1,1,1]` |
| i=2 | `ans[2] = ans[1]*nums[1]=1*2` | `[1,1,2,1]` |
| i=3 | `ans[3] = ans[2]*nums[2]=2*4` | `[1,1,2,8]` |

After the prefix pass: `ans = [1,1,2,8]`  
Now, compute the suffix by traversing from right to left of array, `suffix = product of elements after index`

| index(i) | suffix | `ans[i]=ans[i]*suffix` | `ans[]` |
| :---- | :---- | :---- | :---- |
| start | 1 |  | `[1,1,2,8]` |
| i=2 | `suffix = nums[3]=16=6` | `ans[2] = 2*6=12` | `[1,1,12,8]` |
| i=1 | `suffix = nums[2]=64=24` | `ans[1] = 1*24=24` | `[1,24,12,8]` |
| i=0 | `suffix = nums[1]=242=48` | `ans[0] = 1*48=48` | `[48,24,12,8]` |

Hence, Final Output = `[48,24,12,8]`  
**Test Case2:**  
Input: `nums=[-1,0,1,2,3]`  
Output: `[0,-6,0,0,0]`  
Explanation:  
Now the same thing also happens here.  
After prefix pass: `ans=[1,-1,0,0,0]`  
After suffix pass: `ans=[0,-6,0,0,0]` which is the final output.

### Solution:

```java  
class Solution {  
    public int[] productExceptSelf(int[] nums) {  
        int n=nums.length;  
        int[] ans=new int[n];  
        Arrays.fill(ans, 1);  
        for(int i=1;i<n;i++){  
            ans[i]=ans[i-1]*nums[i-1];  
        }  
        int suffix=1;  
        for(int i=n-2;i>=0;i--){  
            suffix*=nums[i+1];  
            ans[i]*=suffix;  
        }  
        return ans;  
    }  
}    
```  
Now, here 2 loops are running so Time complexity becomes `O(2*n)`, but we can ignore the constant, so `T(n) = O(n)`  
Space complexity = `O(1)` excluding the output array.
