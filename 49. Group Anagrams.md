# 49. Group Anagrams

## Problem Statement-

Given an array of strings `str`, group all anagrams together into sublists. Return output in any order.

## Understanding the Problem Statement-

A String array `str` is given, which contains words. An anagram is a string that contains exactly same characters in another string but the order can be different. It is very similar to the “Valid Anagram” problem, where we only had to check whether 2 strings are anagrams or not. Here, we return sublists of string array.

## Hash Table Approach-

We are using this approach as it gives a better time complexity, instead of sorting.   
Here, we represent every string by frequency of characters. The problem states that only lowercase characters are used. So, we create a fixed array of length `26` and store how many times each character appears in it. Through this frequency array, we group all strings with same character count and if these arrays are identical then the strings are identical.

### Algorithm:

1. For creating character frequencies, create a hash map of length 26 and each value is list of strings that belong to anagram group.  
2. For each string in the input:  
* Initialize frequency array of size `26` and fill with `0s.`  
* Increment count at corresponding index, for each character in the string.  
* Append string to list associated with this key.  
3. After processing all strings, return all lists stored in hash map.

Output: `[["hat"],["act", "cat"],["stop", "pots", "tops"]]`  
Explanation: 

| String | `cnt`(count array) | Key(`Arrays.toString(cnt)`) | Map after adding |
| :---- | :---- | :---- | :---- |
| `“act”` | a=1, c=1, t=1 `[1,0,0,1,...0,1]` | `"[1,0,0,1,...,0,1]"` | `{ "[1...]" : ["act"] }` |
| `”pots”` | o=1, p=1, s=1, t=1 | key1 | `{ key1 : ["act"], key2 : ["pots"] }` |
| `”tops”` | Same cnt as `”pots”` | Same key2 | `{ key2 : ["pots","tops"] }` |
| `”cat”` | Same cnt as `”act”` | Same key1 | `{ key1 : ["act","cat"] }` |
| `”stop”` | Same cnt as `”pots”, “tops”` | Same key2 | `{ key2 : ["pots","tops","stop"] }` |

### Solution:

```java  
public class Solution {  
    public List<List<String>> groupAnagrams(String[] strs) {  
        Map<String, List<String>> res = new HashMap<>();  
        for (String s : strs) {  
            int[] count = new int[26];  
            for (char c : s.toCharArray()) {  
                count[c - 'a']++;  
            }  
            String key = Arrays.toString(count);  
            res.putIfAbsent(key, new ArrayList<>());  
            res.get(key).add(s);  
        }  
        return new ArrayList<>(res.values());  
    }  
}  
```  
Now, since m = number of strings and n = length of longest string  
We traverse each string and build count array which takes `O(n)`  
And convert count array into single key which is a constant.  
So total: `O(n) per string * m strings = O(m*n)`  
Similarly, Space Complexity = `O(m*n)`.
