# 242. Valid Anagram
## Problem Statement-
Given two strings `s` and `t` , return `true` if `t` is anagram of `s`, and `false` otherwise.

## Understanding the Problem Statement-
An anagram is a string that contains the exact same characters as another string, but order of characters can be different.  
Here, two strings `s` and `t` will be given, and they will contain same characters with same frequencies.  
So we have to check for the same, if they match then return `true`, else `false`.

## 1) Sorting Approach-
Since both strings have exactly the same characters with same frequencies, by sorting all characters will be arranged in an order.  
And if both strings will be identical, then every character and count will match which means string is anagram.
### Algorithm:
1. If lengths of both strings are not equal, they are not anagram  
2. Sort both strings.  
3. Compare both strings.  
* If equal, return `true`  
* Otherwise `false`

### Working with Test Cases:
**Test Case1**:  
Input: `s = “anagram”`,  `t = “nagaram”  `
Output: `true  `
Explanation:  
String `s` is `anagram` and `t` is `nagaram`.   
Sorted string `s: aaagmnr`, and `t: aaagmnr.`  
Now when we go through both of the strings, they are identical, so output is `true`. 

**Test Case2**:  
Input: `s=”rat”, t=”car”`  
Output: `false`  
Explanation:
String s is rat and t is car.
Sorted string `s:art`, and `t:acr.`  
Here we can see, although the length of both strings are same, the strings are not identical that is both have different characters.
Hence output is `false.`

### Solution:
```java  
class Solution {  
    public boolean isAnagram(String s, String t) {  
        if(s.length() != t.length()){  
            return false;  
        }  
        char[] sch = s.toCharArray();  
        char[] tch = t.toCharArray();  
        Arrays.sort(sch);  
        Arrays.sort(tch);  
        return Arrays.equals(sch,tch);  
    }  
}  
```
Now since we are using `Arrays.sort(arr)` function, Time Complexity becomes `O(nlogn)` since it uses Quick Sort technique.  
Time Complexity = `O(nlogn + mlogm)`, where n=length of string s, and m=length of string t  
Space Complexity = `O(1)`.

## 2)Hash Table-  
Here, we observe that the characters in string are lowercase, so we can use a fixed-size array of length `26` to count character frequencies.  
We iterate through both strings simultaneously and increment count for each character in `s` and decrement count for each character in `t`.  
If strings are anagrams, every increment is matched by a decrement, and all values in array will end at 0.

### Algorithm:
1. If both strings differ in length, they are not anagrams.  
2. Create a fixed size frequency array `count` of size `26` initalised to 0.  
3. Iterate through both strings:  
* Increment count at index corresponding to `s[i]`  
* Decrement count at index corresponding to `t[i]`  
4. After both strings are processed, scan the `count` array. If any value is not zero, return `false` as the frequencies differ.  
5. If all values are zero, return `true` since strings are anagrams.

### Working with Test Cases:
**Test Case 1**:  
Input: `s=”anagram”, t=”nagaram”  `
Output: `true  `
Explanation:  
A loop runs until size of the string. In the `count` array, for string `s,`we increment the value by subtracting the ASCII value of `a(97)`.  
For string `t`, we decrement the value by subtracting ASCII value of `a`(97).  
Then an advanced for loop is executed which checks if the value in array ending is not equal to 0, then returns `false`.   
Otherwise it returns `true`

### Solution:
```java  
public class Solution {  
    public boolean isAnagram(String s, String t) {  
        if (s.length() != t.length()) {  
            return false;  
        }  
        int[] count = new int[26];  
        for (int i = 0; i < s.length(); i++) {  
            count[s.charAt(i) - 'a']++;  
            count[t.charAt(i) - 'a']--;  
        }  
        for (int val : count) {  
            if (val != 0) {  
                return false;  
            }  
        }  
        return true;  
    }  
}  
```  
Now this has a Time complexity of `O(n+m)` where n is length of string s and m is length of string t.  
Space complexity = O(1).
