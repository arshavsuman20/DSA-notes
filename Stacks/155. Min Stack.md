# 155. Min Stack

## Problem Statement-

Design a stack that supports push, pop, top, and retrieving the minimum element in constant time.

## Understanding the Problem Statement-

Implement the `MinStack` class:

* `MinStack()` initializes the stack object.  
* `void push(int val)`pushes element `val` onto the stack.  
* `void pop()` removes element on top of stack.  
* `int top()`gets top element of stack.  
* `int getMin()`retrieves minimum element in stack.

## 1. Brute Force Approach-

To get the minimum value, this approach simply looks through all elements in the stack.  
Since a normal stack does not store any extra information about the minimum, the only way to find it is to temporarily remove every element, track the smallest one, and then put everything back.  
It's easy to understand but slow because each `getMin` call scans the entire stack.

### Algorithm:

1. To `push` a value, append it to stack.  
2. To `pop`, remove top element of stack.  
3. To `top`, return last element.  
4. To `getMin`:  
    * Create a temporary list.  
    * Pop all elements from stack while tracking smallest value.  
    * Push all elements back from temporary list to restore the stack.  
    * Return smallest value found.

### Working with Test Cases:

Input: `["MinStack", "push", 1, "push", 2, "push", 0, "getMin", "pop", "top", "getMin"]`  
Output: `[null,null,null,null,0,null,2,1]`  
Explanation:  
MinStack minStack = new MinStack();  
minStack.push(1);  
minStack.push(2);  
minStack.push(0);  
minStack.getMin(); // return 0  
minStack.pop();  
minStack.top();    // return 2  
minStack.getMin(); // return 1  
So, this output is obtained.

### Solution:

```java  
class MinStack {

    private Stack<Integer> stack;

    public MinStack() {  
        stack = new Stack<>();  
    }

    public void push(int val) {  
        stack.push(val);  
    }

    public void pop() {  
        stack.pop();  
    }

    public int top() {  
        return stack.peek();  
    }

    public int getMin() {  
        Stack<Integer> tmp = new Stack<>();  
        int mini = stack.peek();

        while (!stack.isEmpty()) {  
            mini = Math.min(mini, stack.peek());  
            tmp.push(stack.pop());  
        }

        while (!tmp.isEmpty()) {  
            stack.push(tmp.pop());  
        }

        return mini;  
    }  
}  
```  
Here, the Time complexity is `O(n)` for getMin() and `O(1)` for other operations.  
Space complexity is `O(n)` for getMin() and `O(1)` for other operations.

## 2. Stacks Approach-

This approach keeps only one stack and stores encoded values instead of actual numbers.  
Trick is to record the difference between pushed value and current minimum.  
Whenever a new minimum is pushed, we store a negative encoded value, which signals that minimum has changed.  
Later, when popping such a value, we can decode it to restore previous minimum.  
This way, stack internally keeps track of all minimum updates without needing a second stack - giving constant - time operations with minimal space.

### Algorithm:

1. Maintain:  
    * `st` that stores encoded values(not the actual numbers)  
    * `min`: stores current minimum in stack.  
2. Push(val):  
    * If stack is empty:  
        * Push `0`(difference) and set `min = val`.  
    * Otherwise:  
        * Push `val - mini`  
    * If `val` is new minimum, update `min`.  
3. Pop():  
    * Pop the encoded value.  
    * If value is negative, means that popped element was minimum.  
    * Restore previous minimum using encoded difference.  
4. Top():  
    * If encoded value is , return `encoded + min`.  
    * If it’s negative, top actual value is simply `min`.  
5. getMin():  
    * Return current `min`.

### Working With Test Cases:

Input: `["MinStack", "push", 1, "push", 2, "push", 0, "getMin", "pop", "top", "getMin"]`  
Output: `[null,null,null,null,0,null,2,1]`  
Explanation:

| Operation | Stack | mini | Explanation | Output |
| :---- | :---- | :---- | :---- | :---- |
| MinStack | [] | +inf | Constructer initializes stack and mini | null |
| push(1) | [1] | 1 | Stack empty -> push normally, update mini | null |
| push(2) | [1,2] | 1 | `2>mini` so push noramlly | null |
| push(0) | [1,2,-1] | 0 | `0<=mini` so push -1, update mini | null |
| getMin() | [1,2,-1] | 0 | Mini is current minimum | 0 |
| pop() | [1,2] | 1 | Popped `-1<mini` so restore old min: 1 | null |
| top() | [1,2] | 1 | Top = 2(`2>mini`) | 2 |
| getMin() | [1,2] | 1 | Mini remains 1 | 1 |

So, final output is `[null, null, null, null, 0, null, 2, 1]`

### Solution:

```java  
class MinStack {  
    Stack<Long> st;  
    long mini;  
    public MinStack() {  
        st=new Stack<>();  
        mini=Integer.MAX_VALUE;  
    }  
    public void push(long val) {  
        if(st.isEmpty()){  
            mini=val;  
            st.push(val);  
            return;  
        }  
        if(val>mini) st.push(val);  
        else{  
            st.push(2*val-mini);  
            mini=val;  
        }  
    }  
    public void pop() {  
        if(st.isEmpty())return;  
        long x=st.pop();  
        if(x<mini) mini=2*mini-x;  
    }  
    public int top() {  
        if(st.isEmpty()) return -1;  
        long x=st.peek();  
        if(mini<x) return (int)x;  
        return (int)mini;  
    }  
    public int getMin() {  
        return (int)mini;  
    }  
}  
```  
So for all operations, Time complexity is `O(1)` and Space complexity is `O(n)`.
