# 853. Car Fleet

## Problem Statement-

There are `n` cars at given miles away from the starting mile 0, travelling to reach the mile `target`.  
We are given two integers array `positions` and `speed`, both of length `n`, where `positions[i]` is the starting mile of the `ith` car in miles per hour.  
A car cannot pass another car, but it can catch up and then travel next to it at the speed of slower car.  
A **car fleet** is a single car or a group of cars dividing next to each other. The speed of car fleet is the **minimum** speed of any car in the fleet.  
If a car catches up to a car fleet at the mile `target`, it will still be considered as part of the car fleet.  
Return the number of car fleets that will arrive at the destination.

## Understanding the Problem Statement-

A car cannot pass another car ahead. They can only catch upon and drive with same speed. Fleet is non-rempty set of cars at same position and same speed.  
We have to return the number of car fleets when they arrive at the destination.

## 1. Stack Approach-

Each car moves towards the same target.  
A faster car cannot overtake a slower car in front of it.  
So instead of simulating movement, we only care about time to reach the target.  
If a car behind reaches the target ealier or at the same time as the car in front, it will catch up and form one fleet.  
So, we sort cars from closest to target -> farthest  
Use a monotonic stack of times to track fleets.

### Algorithm:

1. Create a `temp` array where:  
    * `temp[i][0] = position[i]`  
    * `temp[i][1] = speed[i]`  
2. Sort cars by position descending(closest to target first).  
3. Use a stack to store time to reach target:  
    * `time = (target - position) / speed`  
4. For each car:  
    * Push its time onto the stack,  
    * If the current car’s time <= time of the car ahead(top-1):  
        * They merge into one fleet  
        * Pop the current time.  
5. Stack size at the end = number of fleets.

### Working of Test Cases:

Input: `target=10`, `position=[1,4]` , `speed=[3,2]`  
Output: `1`  
Explanation:  
Combine position and speed: `temp = [[1,3], [4,2]]`  
Sort by descending position: `temp = [[4,2], [1,3]]`  
We need to process Stack:  
Car position is at 4:  
`Time = (10 - 4) / 2 = 3.0`  
`stack = [3.0]`  
Car position is at 1:  
`Time = (10 - 1) / 3 = 3.0`  
`Stack = [3.0, 3.0]`  
Now we check: `3.0<=3.0 -> true`  
And, Second car catches up -> merge fleets.  
Pop: `Stack = [3.0]`  
So, final answer: Number of fleets = stack.size() - 1

### Solution:

```java  
class Solution {  
    public int carFleet(int target, int[] position, int[] speed) {  
        int[][] temp=new int[position.length][2];  
        for(int i=0;i<position.length;i++){  
            temp[i][0]=position[i];  
            temp[i][1]=speed[i];  
            //[temp[i][0]=position[i], temp[i][1]=speed[i]];  
        }  
        //sort cars according to target's closest to farthest  
        Arrays.sort(temp,(a,b)->Integer.compare(b[0],a[0]));  
        Stack<Double> st=new Stack<>();//time to reach store (Target-position)/speed  
        for(int[] t:temp){  
            st.push((double)(target-t[0])/t[1]);  
            if(st.size()>=2 && st.peek() <= st.get(st.size()-2)){  
                st.pop();  
            }  
        }  
        return st.size();  
    }  
}  
```  
Here, we are building the array which takes `O(n)`, sort the cars which takes `O(nlogn)` and for stack traversal we take `O(n)`. So, overall Time complexity is `O(n*logn)`.  
We are also creating a `temp` array of size `n` which gives us `O(n)` and for stack, the worst case is `O(n)`. So, overall Space complexity is `O(n)`.
