# 875. Koko Eating Bananas

## Problem Statement-

Koko loves to eat bananas. There are `n` piles of bananas, the `ith` pile has `piles[i]` bananas. The guards have gone and will come back in `h` hours.  
Koko can decide her bananas-per-hour eating speed of `k`. Each hour, she chooses some piles of bananas and eats `k` bananas from that pile. If the pile has less than `k` bananas, she eats all of them instead and will not eat any more bananas during this hour.  
Koko likes to eat slowly but still wants to finish eating all the bananas before the guards return.  
Return the minimum integer `k` such that she can eat all the bananas within `h` hours.

## Understanding the Problem Statement-

We are given an integer array `piles` where `piles[i]` is the number of bananas in `ith` pile. `H` represents number of hours we have to eat all the bananas.   
Our bananas-per-hour eating rate is `k`. Each hour, we may choose a pile of bananas and eats `k` bananas from that pile. If the pile has less than `k` bananas, we may finish eating pile but we cannot each another pile in same hour.  
We return the minimum integer `k` such that we can eat all the bananas within `h` hours.

## 1. Brute Force Approach-

We try every possible eating speed starting from `1`.  
For each speed, we simulate how many hours it would take to finish all piles.  
The first speed that finishes within `h` hours is the answer.

### Algorithm:

1. Start with `speed=1`.  
2. For each speed:  
    * Compute the total hours needed by summing `ceil(pile/speed)` for every pile.  
3. If the total hours is less than or equal to `h`, return current speed.  
4. Otherwise, increase speed and repeat.


### Working with Test Cases:

Input: `piles = [3, 6, 7, 11]`, `h=8`  
Output: `4`.  
Explanation:  
When `speed = 1`, `totalTime = 27`,   
When `speed = 2`, `totalTime = 15`,  
When `speed = 3`, `totalTime = 10`,  
When `speed = 4`, `totalTime = 8`.  
At speed = 4, total hours <= h, so output is `4`.

### Solution:

```java  
public class Solution {  
    public int minEatingSpeed(int[] piles, int h) {  
        int speed = 1;  
        while (true) {  
            long totalTime = 0;  
            for (int pile : piles) {  
                totalTime += (int) Math.ceil((double) pile / speed);  
            }

            if (totalTime <= h) {  
                return speed;  
            }  
            speed++;  
        }  
    }  
}  
```
  
So, here overall Time complexity is `O(m*n)`, where n is the length of input array piles, and m is the maximum number of bananas in a pile.

## 2. Binary Search Approach-

Eating speed `k` is between 1 and max(piles).  
If koko eats too slow, total hours > h.  
If she eats fast enough, total hours <= h.  
As speed increases, required hours decrease -> monotonic. 

### Algorithm:

1. `low = 1`(minimum speed)  
2. `high = max(piles)`(maximum possible speed)  
3. While `low<=high`:  
    * `Mid` = current eating speed  
    * Calculate total hours needed at speed `mid`  
    * If `totalHours <= h`  
        * Speed is valid, try smaller speed (`high=mid-1`)  
    * Else   
        * Speed too slow(`low=mid+1`).  
4. Return `low`(minimum valid speed).

### Working with Test Cases:

Input: `piles = [3, 6, 7, 11]`, `h=8`  
Output: `4`.  
Explanation:  
`piles = [3,6,7,11]`, `h = 8`  
`low = 1`, `high = 11`  
Iteration 1:  
`mid = 6`  
hours = ⌈3/6⌉ + ⌈6/6⌉ + ⌈7/6⌉ + ⌈11/6⌉  
      = 1 + 1 + 2 + 2 = 6  
`6 <= 8 → valid`   
`high = 5`  
Iteration 2:  
`mid = 3`  
`hours = 1 + 2 + 3 + 4 = 10`  
`10 > 8 → too slow`  
`low = 4`  
Iteration 3:  
`mid = 4`  
`hours = 1 + 2 + 2 + 3 = 8`  
`8 <= 8 → valid`  
`high = 3`  
Loop ends since `low>high`. So answer is `4`.

### Solution:

```java  
class Solution {  
    public int minEatingSpeed(int[] piles, int h) {  
        int low=1;   
        int high=findmax(piles); //max needed speed  
        while(low<=high){  
            int mid=(low+high)/2; //current speed  
            int totalh=totalhours(piles,mid);  
            if(totalh<=h){  
                high=mid-1;  
            }  
            else{  
                low=mid+1;  
            }  
        }  
        return low;  
    }  
    int findmax(int[] arr){  
        int m=Integer.MIN_VALUE; int n=arr.length;  
        for(int i=0;i<n;i++){m=Math.max(m,arr[i]);}  
        return m;  
    }  
    int totalhours(int[] arr,int h){  
        int totalh=0;int n=arr.length;  
        for(int i=0;i<n;i++){  
            totalh+=Math.ceil((double)arr[i] / (double) h);  
        }  
        return totalh;  
    }  
}  
```  
Here, binary search range is `log(maxPile)` and each check takes `O(n)`, so overall Time complexity is `O(n*log(maxPile))`.  
Overall Space Complexity is `O(1)`.
