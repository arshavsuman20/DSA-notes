# 15. 3Sum

## Problem Statement-

Given an integer array `nums`, return all triplets `[nums[i], nums[j], nums[k]]`, such that `i!=j`, `i!=k` and `j!=k`, and `nums[i] + nums[j] + nums[k] = 0`. Also, the solution must not contain duplicate triplets.

## Understanding the Problem Statement-

The problem statement is pretty simple, and this problem is advanced version of the 2Sum problem where we only had to return the 2 indices of array. So, according to this problem statement, the triplet of indices whose value’s sum equals target should not be equal, they must be **distinct**.

## 1) Brute Force Approach-

We check all combinations of `(i,j,k)` with `i<j<k` to find lal sets of three numbers that sum to `0`. Sorting helps in keeping triplets in order and is easy to avoid duplicates by storing them in a set. But this is not the most efficient way to solve the problem.

### Algorithm:

1. Sort the array for handling duplicates.  
2. Create empty set `res` to store triplets.  
3. Use three nested loops:  
    * For each `i`,  
    * For each `j>i`,  
    * For each `j>k`,  
        - Check if `nums[i] + nums[j] + nums[k] == 0.`  
        - If true, add sorted triplet to set.  
4. Convert the set to lists.  
5. Return the result.

### Working with Test Cases:

**Test Case1:**  
Input: `nums = [-1, 0, 1, 2, -1, -4]`  
Output: `[[-1, -1, 2], [-1, 0, 1]]`  
Explanation:  
The Sorted array becomes: `[-4, -1, -1, 0, 1, 2]`  
Now the three loops run nestedly, and then `nums[i]+nums[j]+nums[k]==0` is checked, whenever it is found, we add it to a List and then that list into a set.  So, 
`nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0`  
`nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0`  
`nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0.`  
The distinct triplets are : `[-1,0,1]` and `[-1,-1,2]`.

**Test Case2:**  
Input: `nums = [0,1,1]`  
Output: `[]`  
Explanation:  
Here there are already three elements, and their sum eventually does not equals 0. So output is empty list.

**Test Case3:**  
Input: `nums=[0, 0, 0]`  
Output: `[[0, 0, 0]]`  
Explanation:  
Here the only triplets that sum up to zero are these three indices itself, so output is `[[0,0,0]]`.

### Solution:

```java  
public class Solution {  
    public List<List<Integer>> threeSum(int[] nums) {  
        Set<List<Integer>> res = new HashSet<>();  
        Arrays.sort(nums);  
        for (int i = 0; i < nums.length; i++) {  
            for (int j = i + 1; j < nums.length; j++) {  
                for (int k = j + 1; k < nums.length; k++) {  
                    if (nums[i] + nums[j] + nums[k] == 0) {  
                        List<Integer> tmp = Arrays.asList(nums[i], nums[j], nums[k]);  
                        res.add(tmp);  
                    }  
                }  
            }  
        }  
        return new ArrayList<>(res);  
    }  
}  
```  
Now, since three for loops are running nestedly, so, `T(n) = O(n3)`.  
and `S(n) = O(m)`, where n = length of array and m = number of triplets.

## 2) Hashing Approach-

We use a hash map that stores how many times each number appears. As we pick the first and second numbers, we reduce their counts int the map temporarily so that we don’t reuse them. Then we check whether the third value exists in the map.

### Algorithm:

1. Sort array to organize duplicates.  
2. Build frequency map `count` for numbers.  
3. Initialize empty list `res` for storing valid triplets.  
4. Loop through each index `i`:  
    * Decrease count of `nums[i]`   
    * Skip duplicates of first element  
    * Loop through each index `j>i`:  
        - Decrease count of `nums[j]`  
        - Skip duplicates of second element  
        - Compute third value: `target = -(nums[i]+nums[j])`  
        - If `target` still has positive count, add triplet.  
5.  After finishing `j` ,restore counts for second loop by adding back decremented values.  
6. Return `res` containing all found triplets.

### Working with Test Cases:

Input: `nums = [-1, 0, 1, 2, -1, -4]`  
Output: `[[-1, -1, 2], [-1, 0, 1]]`  
Explanation:  
The Sorted array becomes: `[-4, -1, -1, 0, 1, 2]`  
Count freq map:   
-4 → 1  
-1 → 2  
0 → 1  
1 → 1  
2 → 1  
For `i=0`, `nums[i]=-4`, and count is updated to `0`.  
`i=1 → nums[i]=-1`  
Then the `j` loop continues, which finds triplets: `[-1,-1,2]` and `[-1,0,1]`.

**Test Case2:**  
Input: `nums = [0,1,1]`  
Output: `[]`  
Explanation:  
→ i=0 (0), j=1 (1) → target = -(0+1) = -1 → count[-1]=0 → No  
→ j=2 → target = -(0+1)= -1 → No  
→ i=1 → nums[i]=1  
→ j=2 → target = -(1+1) = -2 → No  
So output is empty list.

**Test Case3:**  
Input: `nums=[0, 0, 0]`  
Output: `[[0, 0, 0]]`  
Explanation:  
i = 0 → decrement count[0] → 2  
j = 1 → decrement count[0] → 1  
target = -(0 + 0) = 0  
count[0] = 1 → valid  
➡ Add → `[0,0,0]`  
i = 1 → skip duplicates  
i = 2 → skip  
Output**:** `[[0,0,0]]`

### Solution:

```java  
public class Solution {  
    public List<List<Integer>> threeSum(int[] nums) {  
        Arrays.sort(nums);  
        Map<Integer, Integer> count = new HashMap<>();  
        for (int num : nums) {  
            count.put(num, count.getOrDefault(num, 0) + 1);  
        }

        List<List<Integer>> res = new ArrayList<>();  
        for (int i = 0; i < nums.length; i++) {  
            count.put(nums[i], count.get(nums[i]) - 1);  
            if (i > 0 && nums[i] == nums[i - 1]) continue;

            for (int j = i + 1; j < nums.length; j++) {  
                count.put(nums[j], count.get(nums[j]) - 1);  
                if (j > i + 1 && nums[j] == nums[j - 1]) continue;

                int target = -(nums[i] + nums[j]);  
                if (count.getOrDefault(target, 0) > 0) {  
                    res.add(Arrays.asList(nums[i], nums[j], target));  
                }  
            }

            for (int j = i + 1; j < nums.length; j++) {  
                count.put(nums[j], count.get(nums[j]) + 1);  
            }  
        }  
        return res;  
    }  
}  
```  
Now this has `T(n) = O(n2)` and `S(n) = O(n)`.

## 3) Two Pointers Approach-

Here sorting helps in two ways:
    * Lets us skip duplicates  
    * Ensures that moving left or right pointer will increase or decrease sum in particular way.
For each fixed number, we place two pointers:
    * `left` starts just after `i`.  
    * `right` starts at end.
If current sum is too large we move `right` left to reduce it, and if current sum is too small we move `left` right to increase it.

### Algorithm:

1. Sort array to handle duplicates and enable two pointer logic.  
2. Loop through array using index `i`:  
    * If `nums[i] > 0` exit the loop.(all remaining numbers are positive).  
    * Skip duplicate values for first number.  
3. Set two pointers:   
    * `left = i+1`  
    * `right = size of array - 1`  
4. While `left<right`:  
    * Compute `sum=nums[i] + nums[left] + nums[right]`  
    * If `sum>0`, move `right` to left.  
    * If `sum<0`, move `left` to right.  
    * If `sum==0`:  
        - Add triplet to result,  
        - Move both pointers inward,  
        - Skip duplicates at left pointer.  
5. Return list of valid triplets.

### Working with Test Cases:

**Test Case1:**  
Input: `nums = [-1, 0, 1, 2, -1, -4]`  
Output: `[[-1, -1, 2], [-1, 0, 1]]`  
Explanation:  
`i=0`, `left=1`, `right=5`. While condition satisfied: `sum = nums[0]+nums[1]+nums[right] = (-1) + (0) + (-4) = -5`., now sum is less than 0, so increase left pointer.  
`left=2`, `right=5`, `sum=(-1) + (1) + (-4) = -4`, so `left=3`.  
`sum=(-1) + 2 + (-4) = -3`, `left=4`. So here we observe that value of sum is increasing slowly and when it reaches `0`, we find the triplet.  
So output = `[[-1, -1, 2], [-1, 0, 1]]`

**Test Case2:**  
Input: `nums = [0,1,1]`  
Output: `[]`  
Explanation:  
Here while executing, we observe that the sum value can never be equal to 0, so output is empty list.

**Test Case3:**  
Input: `nums=[0, 0, 0]`  
Output: `[[0, 0, 0]]`  
Explanation:  
`i=0:`  
`left=1`, `right=2`, `sum=0+0+0=0`, `ans=[[0,0,0]]`,  
`left=2`, `right=1`, loop stops because `left>right`.  
`i=1`:   
`nums[i]=0`  
Checks duplicate: `nums[1]==nums[0] → continue`  
`i=2:`  
`nums[2]=0`  
Again skips,  
So `output=[[0,0,0]]`.

### Solution:

```java  
class Solution {  
    public List<List<Integer>> threeSum(int[] nums) {  
        Arrays.sort(nums);  
        List<List<Integer>> ans=new ArrayList<>();  
        for(int i=0;i<nums.length;i++){  
            if(nums[i]>0) break;  
            if(i>0 && nums[i]==nums[i-1]) continue;  
            int left=i+1;  
            int right=nums.length-1;  
            while(left<right){  
                int sum=nums[i]+nums[left]+nums[right];  
                if(sum==0){  
                    ans.add(Arrays.asList(nums[i],nums[left],nums[right]));  
                    left++;  
                    right--;  
                    while(left<right && nums[left]==nums[left-1])left++;  
                }  
                else if(sum>0) right--;  
                else left++;  
            }  
        }  
        return ans;  
    }  
}  
```  
So, here the time complexity is quadratic since inside for loop there is a while loop: `T(n) = O(n2)`.  
Space complexity might be `O(1)` or `O(n)` depending upon the sorting algorithm OR `O(m)` for output list.
