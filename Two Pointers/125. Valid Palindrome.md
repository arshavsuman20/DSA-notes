# 125. Valid Palindrome

## Problem Statement-

Given a string `s`, return `true` it is a *palindrome*, or `false` otherwise.

## Understanding the Problem Statement-

A phrase is a **palindrome** if, after converting all uppercase characters into lowercase letters and removing all non-alphanumeric characters, it reads the same forward and backward. (Alphanumeric characters are those that contains letters and numbers).

## Two Pointer Approach-

We check if a string is palindrome in-place by using two pointers. One pointer `start` starts at the beginning and the `end` pointer at the end.  
The `start` pointer moves towards end and `end` pointer moves towards start, and we skip if there is any alphanumeric character present.   
If the character at `start` and character at `end` are the same, then return `true` otherwise `false`.

### Algorithm:

1. Initialize two pointers:   
* `st`: at start of string,  
* `end`: at end of string.  
2.  While `st` is less than `end`:  
* Move `st` forward until it points to an alphanumeric character.  
* Move `end` backward until it points to an alphanumeric character.  
* Compare lowercase characters at `start` and `end`: If they don’t match, return `false`.  
* Move both pointers inward: `st+=1`, `end-=1`.  
3.  If loop finishes without mismatches, return `true`.  
4. Create a function to check for alphanumeric characters.

### Working with Test Cases:

**Test Case1:**  
Input: `s = “A man, a plan, a canal: Panama”`  
Output: `true`  
Explanation:  
Convert the string to lowercase: “a man, a plan, a canal: panama”.  
`st=’a’` and `end = ‘a’` . Both are same so move inward. Spaces and commas are ignored because of `isAlpha()` function.  
So when the pointers move inward, it is found that characters at `st=end` and output is `true`.  
**Test Case2:**  
Input: `s = “race a car”`  
Output: `false`  
Explanation:  
The string is already in lowercase. While iterating, the character `e!=c`, so a mismatch occurs. So Output is `false`.  
**Test Case3:**  
Input: `s = “ “`  
Output: `true`  
Explanation:  
Here the string is empty and by definition, empty string is considered a palindrome because reading it forward and backwards gives the same result. So output is `true`.

### Solution:

```java  
class Solution {  
    public boolean isPalindrome(String s) {  
        s=s.toLowerCase();  
        int st=0, end=s.length()-1;  
        while(st<end){  
            if(!isAlpha(s.charAt(st))){  
                st++; continue;  
            }  
            if(!isAlpha(s.charAt(end))){  
                end--;continue;  
            }  
            if(s.charAt(st) != s.charAt(end)){  
                return false;  
            }  
            st++; end--;  
        }  
        return true;  
    }  
    boolean isAlpha(char ch){  
        if((ch>='0' && ch<='9') ||(ch>='a' && ch<='z')){  
            return true;  
        }  
        return false;  
    }  
}  
```  
Now, since total operations is, number of characters in string, so,  
`Time complexity = O(n)` and `Space Complextiy = O(1)`.
