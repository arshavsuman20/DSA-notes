# 167. Two Sum II - Input Array is Sorted

## Problem Statement-

Given a **1-indexed** array of integers `numbers` that is already **sorted in non-decreasing order**, find two numbers such that they add up to a specific `target` number. Let these two numbers be `numbers[index1]` and `numbers [index2]` where `1 <= index1 < index2 <= numbers.length`.  
Return the indices of two numbers, `index1` and `index2`, *added by one* as an integer array `[index1, index2]` of length 2.

## Understanding the Problem Statement-

There is an array `numbers` that has already been sorted in **ascending** order. This is a **1-indexed array**, which means that indexing will start from 1 instead of 0. Also this is an extended version of Two Sum I problem, only here we can not use the same element twice. Along with this, the problem needs to be solved in `O(1)` extra space, so we must solve this in-place.

## 1) Binary Search Approach-

We don’t need to check every pair because the array is already sorted. For each number at index `i` we need to find `target - numbers[i]`.

### Algorithm:

1. Run a loop `i` from `0` to `n-1`.  
2. For each `numbers[i]`, compute `tmp = target - numbers[i]`.  
3. Perform binary search on subarray from `i+1` to end:  
    * If `numbers[mid] == tmp`, return `[i+1, mid+1]`  
    * If `numbers[mid] < tmp`, search right half  
    * Otherwise left half  
4. If no pair is found after checking all indices, return empty list.

### Working with Test Cases: 

**Test Case1:**  
Input: `numbers  [1,2,3,4], target = 3`  
Output: `[1,2]`  
Explanation:   
For this input,   
When `i=0` : `l=1, r=3`, `tmp=2`, `mid=2`, then perform binary search on the if conditions. After performing the operations, it is found that the first and second index’s sum forms the target, so they are returned.

### Solution:

```java  
public class Solution {  
    public int[] twoSum(int[] numbers, int target) {  
        for (int i = 0; i < numbers.length; i++) {  
            int l = i + 1, r = numbers.length - 1;  
            int tmp = target - numbers[i];  
            while (l <= r) {  
                int mid = l + (r - l) / 2;  
                if (numbers[mid] == tmp) {  
                    return new int[] { i + 1, mid + 1 };  
                } else if (numbers[mid] < tmp) {  
                    l = mid + 1;  
                } else {  
                    r = mid - 1;  
                }  
            }  
        }  
        return new int[0];  
    }  
}  
```  
Now, since binary search is being used, `T(n) = O(n*logn)`, and since we are not using any extra array to store answer, so `S(n) = O(1)`.

## 2) Two Pointer Approach-

For solving this problem more efficiently and in less time complexity, we can use the two-pointer approach.  
If the current sum is too big, we move the right pointer to left which makes the sum smaller.  
If the sum is too small, we move the left pointer to right which makes the sum larger.  
So we close in on the target without checking every pair.

### Algorithm:

1. Initialize two pointers:  
    * `left=0` which is our start,  
    * `right=size of numbers - 1`, which is our end.  
2.  While `left<right`:  
    * Compute the `currsum = numbers[left] + numbers[right].`  
    * If `currsum > target` , move `right` to left to reduce sum.  
    * If `currsum < target`, move `left` to right to increase sum.  
    * If `currsum == target`, return `[left+1, right+1]`.  
3. If no pair matches, then we return an empty list.

### Working with Test Cases:

**Test Case1:**  
Input: `numbers  [1,2,3,4], target = 3`  
Output: `[1,2]`  
Explanation:   
`left=0`, `right=3`, the while condition satisfies, `currsum = 5` , now we see that `currsum > target`, so we update `right = right-1`.  
Then `right=2`, `currsum=4`, still the `currsum>target`, so again `right=right-1`.  
Now, `right=1`, new `currsum=3.` Here we observe that, `currsum==target`, so we return `[1,2]`, since `left=0` and `right=2`.

### Solution:

```java  
class Solution {  
    public int[] twoSum(int[] numbers, int target) {  
        int left=0, right=numbers.length-1;  
        while(left < right){  
            int currsum = numbers[left] + numbers[right];  
            if(currsum>target){  
                right--;  
            }  
            else if(currsum<target){  
                left++;  
            }  
            else{  
                return new int[]{left+1, right+1};  
            }  
        }  
        return new int[0];  
    }  
}  
```  
Now, here we are using two pointers so, `T(n) = O(n)` and `S(n) = O(1)`.
