# 121. Best Time to Buy and Sell Stock

## Problem Statement-

We are given an integer array `prices` where `prices[i]` is price of stock on `ith` day. We may choose a **single day** to buy one stock and choose a **different day in the future** to sell it.  
Return the maximum profit we can achieve. We can also choose **not to make any transactions**, in which case the profit would be `0`.

## Understanding the Problem Statement-

We would be given an integer array `prices` which would be denoting the price of stock on any particular day. Now, we have to choose a single day to buy one stock and a different day in future to sell it. We cannot choose the same day to sell it.  
Problem says to return maximum profit achieved, so we have to ensure that we do not take largest value in array and second largest value in array, as we cannot first sell the stock without buying it. So we have to first buy the stock then sell it.

## 1. Brute Force Approach-

For each day, buy stock and look at future days to see what is the best selling price. Keep highest one among all those.

### Algorithm:

1. Initialize `res=0` to store maximum profit.  
2. Loop through each day `i` as the buy day.  
3. For each buy day loop through each day `j>i` as the sell day.  
4. Calculate profit to be `prices[j] - prices[i]` and update value of `res`.  
5. Return `res` after all pairs.

### Working with Test Cases:

Input: `prices = [10, 1, 5, 6, 7, 1]`  
Output: `6`  
Explanation:  
We have to buy prices at a day and sell it at future day and maximize the profit, so, we know that max profit would be future selling day price - buying day price, so the selling day price should be greater in value than the buying day one.  
Here for 1st index, `10` is the buying day and if we calculate any other value from rest of the array, it does not give maximum profit.  
For 2nd index, buying day’s value is `1`, and we can sell it at `7` to maximize profit to be `6`.  
So `prices[4] = 7`, and `prices[1]=1` and `prices[4]-prices[1] = 7-1 = 6`.  
So output is `6`.

### Solution:

```java  
public class Solution {  
    public int maxProfit(int[] prices) {  
        int res = 0;  
        for (int i = 0; i < prices.length; i++) {  
            int buy = prices[i];  
            for (int j = i + 1; j < prices.length; j++) {  
                int sell = prices[j];  
                res = Math.max(res, sell - buy);  
            }  
        }  
        return res;  
    }  
}  
```  
Now, here since nested loops are used, so `T(n) = O(n^2)`, and `S(n)=O(1)`.

## 2. Optimal Approach-

While traversing the array, we have to keep track of minimum price seen so far. For each day calculate : profit if sold today = today’s price - minimum price seen so far.  
This avoids checking all pairs and solves problem in one pass. For every day, assume I sell today and check if I had bought at the cheapest price before.

### Algorithm:

1. Initialize:  
    * `mini = price on day 0`  
    * `profit = 0`  
2. Traverse array from day 1 to last day:  
    * Calculate profit if sold today: `cost = prices[i] - mini`  
    * Update maximum profit: `profit = max(profit, cost)`  
    * Update minimum price: `mini=min(mini, prices[i])`  
3. Return `profit`

### Working with Test Cases:

Input: `prices = [10, 1, 5, 6, 7, 1]`  
Output: `6`  
Explanation:

| Day | Price | mini | `cost=price-mini` | Max Profit |
| :---- | :---- | :---- | :---- | :---- |
| 0 | 10 | 10 | - | 0 |
| 1 | 1 | 1 | `1-10 = -9` | 0 |
| 2 | 5 | 1 | `5-1 = 4` | 4 |
| 3 | 6 | 1 | `6-1 = 5` | 5 |
| 4 | 7 | 1 | `7-1 = 6` | 6 |
| 5 | 1 | 1 | `1-1 = 0` | 6 |

Best buy at price 1(day 1)  
Best sell at price 7(day 4)  
`Profit = 7-1 = 6`

### Solution:

```java  
class Solution {  
    public int maxProfit(int[] prices) {  
        int n=prices.length;  
        int mini=prices[0];  
        int profit=0, cost=0;  
        for(int i=1;i<n;i++){  
            cost=prices[i]-mini;  
            profit=Math.max(profit,cost);  
            mini=Math.min(mini,prices[i]);  
        }  
        return profit;  
    }  
}  
```  
Since loops are running for array length time so `T(n) = O(n)` and `S(n) = O(1)`.
