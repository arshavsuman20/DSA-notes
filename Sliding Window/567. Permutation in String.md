# 567. Permutation in String

## Problem Statement-

Given, two strings `s1` and `s2`, return `true` if `s2` contains a permutation of `s1`, or `false` otherwise.

## Understanding the Problem Statement-

A permutation is a rearrangement of all characters in string. So, we return `true` if `s1`’s permutations is the substring of `s2`.  
So the problem in itself is pretty straightforward. A string `s1` will be given and `s2` will contain the permutation of `s1` in itself, so we only have to return `true` if it has the permutation, otherwise `false`.

## 1. Brute Force Approach-

Here we try every possible substring of `s2` and checks whether it is a permutation of `s1`.  
To do this, we sort `s1` once, and then for each substring of `s2`, we sort it and compare.  
If the sorted substring matches the sorted `s1`, it means the substring contains exactly the same characters. This method is simple to understand but very slow because it examines all substrings and sorts each one.

### Algorithm:

1. Sort `s1` so we can compare substrings against it.  
2. Loop through every starting index `i` in `s2`.  
3. For each loop `i`, loop through every index `j>=i`:  
* Extract the substring `s2[i : j + 1]`.  
* Sort it and compare with sorted `s1`.  
* If they match, return `true`.  
4. If no matching substring is found, return `false`.

### Working with Test Cases:

Input: `s1 = “abc”`, `s2 = “lecabee”`  
Output: `true`  
Explanation:  
Sort `s1`: `[‘a’, ‘b’, ‘c’]` to string: `“abc”`.  
Outer loop over `s2`.   
Inner loop (substrings starting at `i`):  
At `i=0`:

| i | j | substring | sorted |
| :---: | :---: | :---: | :---: |
| 0 | 0 | “l” | “l” |
| 0 | 1 | “le” | “el” |
| 0 | 2 | “lec” | “cel” |
| 0 | 3 | “leca” | “acel” |
| 0 | 4 | “lecab” | “abcel” |
| 0 | 5 | “lecabe” | abceel” |
| 0 | 6 | “lecabee” | abceeel” |

None equals `“abc”`.  
At `i=1`:

| i | j | substring | sorted |
| :---: | :---: | :---: | :---: |
| 1 | 1 | “e” | “e” |
| 1 | 2 | “ec” | “ce” |
| 1 | 3 | “eca” | “ace” |
| 1 | 4 | “ecab” | “abce” |
| 1 | 5 | “ecabe” | “abcee” |
| 1 | 6 | “ecabee” | “abceee” |

Here also none equals `“abc”`.

At `i=2`:

| i | j | substring | sorted |
| :---: | :---: | :---: | :---: |
| 2 | 2 | “c” | “c” |
| 2 | 3 | “ca” | “ac” |
| 2 | 4 | “cab” | “abc” |

So, here we find “`abc”`.  
So, we return `true` here.

### Solution:

```java  
public class Solution {  
    public boolean checkInclusion(String s1, String s2) {  
        char[] s1Arr = s1.toCharArray();  
        Arrays.sort(s1Arr);  
        String sortedS1 = new String(s1Arr);

        for (int i = 0; i < s2.length(); i++) {  
            for (int j = i; j < s2.length(); j++) {  
                char[] subStrArr = s2.substring(i, j + 1).toCharArray();  
                Arrays.sort(subStrArr);  
                String sortedSubStr = new String(subStrArr);

                if (sortedSubStr.equals(sortedS1)) {  
                    return true;  
                }  
            }  
        }  
        return false;  
    }  
}  
```  
So, here `T(n) = O(n^3 * logn)` and `S(n) = O(n)`, which is not good solution for this problem and also might give Time limit exceeded.

## 2. Sliding Window Approach-

Instead of sorting substrings, we store the frequency of characters in `s1`.  
For every possible window of s1’s length in s2: we build a frequency array for that window, compare it with s1’s frequency.  
If frequencies match then permutation is found.

### Algorithm:

1. Create a frequency of `s1`.  
    * Create an array `freq[26]`  
    * Count how many times each character appears in `s1`.  
2. Fix window size:  
    * `windowSize = s1.length()`  
3. Try all windows in `s2`. For each index `i` in `s2`:  
    * Start a window from index `i`  
    * Build `windowFreq[26]` for next `windowSize` characters  
    * Compare `windowFreq` with `freq`  
    * If same then return `true`.  
4. If no window matches then return `false`.

### Working with Test cases:

Input: `s1 = “abc”`, `s2 = “lecabee”`  
Output: `true`  
Explanation:  
freq: a -> 1, b->2, c->3  
`windowSize = 3`  
Check each window in `s2`:  
Window starting at `i=0`: “lec” ; l->1, e->1, c->1; No matches found  
At `i=1`: “eca” ; e->1, c->1, a->1; Missing `b`, extra `e`  
At `i=2`: “cab” ; c->1, a->1, b->1; Matches freq exactly  
So `true` is returned.

### 

### Solution:

```java  
class Solution {  
    public boolean checkInclusion(String s1, String s2) {  
        int[] freq=new int[26]; //of s1  
        Arrays.fill(freq,0);  
        for(int i=0;i<s1.length();i++){  
            freq[s1.charAt(i)-'a']++; //fill freq of s1  
        }  
        int windowSize=s1.length();//window's size is exactly s1.length  
        for(int i=0;i<s2.length();i++){ //possible window start  
            int windowIdx=0; //chars added in window  
            int idx=i; //current index of s2  
            int windowFreq[]=new int[26]; //freq array of current window  
            Arrays.fill(windowFreq,0);  
            while(windowIdx<windowSize && idx<s2.length()){ //build current window  
                windowFreq[s2.charAt(idx)-'a']++;  
                windowIdx++; idx++;  
            }  
            if(isFreqSame(freq,windowFreq)){  
                return true; // same freq == permutations found  
            }  
        }  
        return false;  
    }  
    boolean isFreqSame(int[] f1,int[] f2){  
        for(int i=0;i<26;i++){  
            if(f1[i] != f2[i]){  
                return false;  
            }  
        }  
        return true;  
    }  
}  
```  
So here overall `T(n) = O(n*k)`, where `O(n)` is for outer loop and `O(k)` is inner loop and `S(n) = O(1)`.
