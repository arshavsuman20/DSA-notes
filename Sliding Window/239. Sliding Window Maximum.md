# 239. Sliding Window Maximum

## Problem Statement-

We are given an array of integers `nums`, there is a sliding window of size `k` which is moving from very left of array to very right. We can only see `k` numbers in window. Each time the sliding window moves right by one position. Return Maximum Sliding Window.

## Understanding the Problem Statement-

We have a sliding window on an array of integers `nums`. The window moves right by one position, so we have to return the max window.

## 1. Brute Force Approach-

For every possible window of size `k`, we simply look at all `k` elements and pick the maximum.  
We slide the window one step at a time, and each time we scan all elements inside it to find the max.  
This method is very easy to understand but slow, because we repeatedly re-scan many of the same elements.

### Algorithm:

1. Create an empty list `output` to store maximum of each window.  
2. For each starting index `i` from `0` to `len(nums) - k`:  
    * Set `maxi` to `nums[i]`  
    * Scan all elements from `i` to `i+k-1` and update `maxi`.  
    * Append `maxi` to `output`.  
3. Return `output` after checking all windows.

### Working with Test Cases:

Input: `nums = [1, 2, 1, 0, 4, 2, 6]`, `k = 3`.  
Output: `[2, 2, 4, 4, 6]`  
Explanation: 

| Window Position | Max |
| :---- | :---- |
| [1, 2, 1], 0, 4, 2, 6 | 2 |
| 1, [2, 1, 0], 4, 2, 6 | 2 |
| 1, 2, [1, 0, 4], 2, 6 | 4 |
| 1, 2, 1, [0, 4, 2], 6 | 4 |
| 1, 2, 1, 0, [4, 2, 6] | 6 |

So, the Brute force approach goes on in nested for loops and updates the value of `maxi` and returns it finally.

### Solution:

```java  
public class Solution {  
    public int[] maxSlidingWindow(int[] nums, int k) {  
        int n = nums.length;  
        int[] output = new int[n - k + 1];

        for (int i = 0; i <= n - k; i++) {  
            int maxi = nums[i];  
            for (int j = i; j < i + k; j++) {  
                maxi = Math.max(maxi, nums[j]);  
            }  
            output[i] = maxi;  
        }

        return output;  
    }  
}  
```  
So, here Time complexity is `O(n * k)` and Space complexity is `O(1)` for extra space and `O(n - k + 1)` for output array.

## 2. Sliding Window and Deque Approach-

For every sliding window of size `k`, we need the maximum element.  
We use a Double Ended Queue (Deque) that stores indices of elements in such a way that:

* Elements are stored in decreasing order of values,  
* Front of deque always holds index of maximum element of current window,  
* Removes elements:  
  * From front if they are out of window,   
  * From back if they are smaller than current element 

### Algorithm:

1. Create a deque to store indices.  
2. Process first `k` elements:  
    * Remove smaller elements from back.  
    * Add current index.  
3. For each element from `k` to `n-1`:  
    * Add `nums[dq.front]` to result  
    * Remove indices from front that are out of current window  
    * Remove smaller elements from back  
    * Add current index.  
4. After loop, add max of last window.  
5. Convert result list to array.

### Working with Test Cases:

Input: `nums = [1, 2, 1, 0, 4, 2, 6]`, `k = 3`.  
Output: `[2, 2, 4, 4, 6]`  
Explanation:   
First window: (indices 0 to 2):

| i | nums[i] | Deque | Explanation |
| :---- | :---- | :---- | :---- |
| 0 | 1 | [0] | Add index 0 |
| 1 | 2 | [1] | Remove 1 |
| 2 | 1 | [1,2] | 1 is smaller than 2 |

Deque values -> `[2,1]` and max=2  
`i=3`: add max=2, then add index 3, deque -> `[1,2,3]`  
`i=4`: add max=2, remove out of window index `1`, remove smaller from back: `0, 1`, add index `4`, so, deque -> `[4]`, And max =4  
For `i=5`: deque = `[4,5]`  
For `i=6`: deque = `[6]`  
And add max of last window -> 6  
Final output: `[2, 2, 4, 4, 6]`

### Solution:

```java  
class Solution {  
    public int[] maxSlidingWindow(int[] nums, int k) {  
        Deque<Integer> dq=new LinkedList<>();  
        ArrayList<Integer> res=new ArrayList<>();  
        //1st window  
        for(int i=0;i<k;i++){  
            while(dq.size() > 0 && nums[dq.getLast()] <= nums[i]) dq.pollLast();  
            dq.addLast(i);  
        }  
        for(int i=k;i<nums.length;i++){  
            res.add(nums[dq.getFirst()]);  
            //remove not part of curr wind  
            while(dq.size()>0 && dq.getFirst() <= i-k)dq.pollFirst();  
            while(dq.size()>0 && nums[dq.getLast()] <= nums[i])dq.pollLast();  
            dq.addLast(i);  
        }  
        res.add(nums[dq.getFirst()]);  
        int[] arr=new int[res.size()];  
        for(int i=0;i<res.size();i++){arr[i]=res.get(i);}  
        return arr;  
    }  
}  
```  
So, Time complexity boils down to `O(n)` since each element is added and removed from queue.  
Space complexity also boils down to `O(n)` since `O(k)` for deque and `O(n)` for result array.
