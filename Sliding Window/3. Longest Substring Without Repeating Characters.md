# 3. Longest Substring Without Repeating Characters

## Problem Statement-

Given a string `s`, find length of the longest substring without duplicate characters. A substring is a contiguous sequence of characters within a string.

## Understanding the Problem Statement-

The problem statement is pretty simple and straight-forward.  
A string is given and we have to find a substring. The length of longest substring without any duplicate characters is the answer.

## 1. Sliding Window Approach-

We keep one window that always has unique characters. We expand the window by moving the right pointer. On encountering a repeated character, we shrink the window from left until duplicate is removed. So, the window always represents a valid substring, ad we track its maximum size.

### Algorithm:

1. Create an empty set `charSet` having two pointers:  
    * `l =` left edge of window  
    * `r =` right edge that moves through string  
2. For each `r`:  
    * While `s[r]` is already in set:  
        - [ ] Remove `s[l]` from set and move `l` right.  
    * Add `s[r]` to set.  
    * Update result with window size: `r - l + 1`  
3. Return the maximum window size found.

### Working with Test Cases:

Input: `s = "abcabcbb"`  
Output: 3  
Explanation:  
When `r=0`, `‘a’` is not in the set so add it. `window= “a”` and `res=1`.  
Similarly, it goes until `r=2`, that is `‘c’` and when `r=3`, that is `a`, we find a match in `charSet`. Then we start shrinking window from left `l`.  
Remove `s[l] = 'a'`, `l = 1.` Now since `‘a’`no longer in set, add it again. Same we do it with `b` and `c`. And again with `b`, `b`.  
So the longest substring length is `3`.

### Solution:

```java  
public class Solution {  
    public int lengthOfLongestSubstring(String s) {  
        HashSet<Character> charSet = new HashSet<>();  
        int l = 0;  
        int res = 0;

        for (int r = 0; r < s.length(); r++) {  
            while (charSet.contains(s.charAt(r))) {  
                charSet.remove(s.charAt(l));  
                l++;  
            }  
            charSet.add(s.charAt(r));  
            res = Math.max(res, r - l + 1);  
        }  
        return res;  
    }  
}  
```  
Now, the Time complexity for this is `O(n)` and Space complexity is `O(m)`.

## 2. Two Pointers Approach-

Instead of restarting from scratch, we slide window forward to remove all duplicates. So we use two pointers (`l` and `r`) to represent a window `[l…r]`. Along with this, we use a hash array to remember the **last index** where each character appeared. Whenever a duplicate is found **inside the current window**, we move `l` just after the previous occurrence.

### Algorithm:

1. Initialize:  
    * `l=0`, `r=0`  
    * `maxlen=0`  
    * `Hash[256]` stores last index of each character  
2. While `r < n`:  
    * If `s[r]` was seen before and its last index >= l  
        - [ ] It’s a duplicate inside the current window  
        - [ ] Move `l` to `hash[s[r]]+1`  
    * Calculate current window length: `len=r-l+1`.  
    * Update `maxlen`  
    * Update `hash[s[r]] = r`  
    * Move `r` forward.  
3. Return `maxlen`.

### Working with Test Cases:

Input: `s = "abcabcbb"`  
Output: 3  
Explanation:

| r | char | l | window | maxlen |
| :---- | :---- | :---- | :---- | :---- |
| 0 | a | 0 | a | 1 |
| 1 | b | 0 | ab | 2 |
| 2 | c | 0 | abc | 3 |
| 3 | a | 1 | bca | 3 |
| 4 | b | 2 | cab | 3 |
| 5 | c | 3 | abc | 3 |
| 6 | b | 5 | cb | 3 |
| 7 | b | 7 | b | 3 |

So, answer is `3`.

### Solution:

```java  
class Solution {  
    public int lengthOfLongestSubstring(String s) {  
        int n=s.length();   
        int l=0, r=0, maxlen=0;  
        int[] hash=new int[256];  
        Arrays.fill(hash,-1);  
        while(r<n){  
            if(hash[s.charAt(r)]!=-1){ //if -1, character already present  
                if(hash[s.charAt(r)]>=l){ //inside current window  
                    l=hash[s.charAt(r)]+1;//if yes increase l  
                }  
            }  
            int len=r-l+1; //curr win len  
            maxlen=Math.max(len,maxlen);   
            hash[s.charAt(r)]=r;//update hash with latest index  
            r++;//expand  
        }  
        return maxlen;  
    }  
}  
```  
Since each character is processed at-most twice, so Time complexity is `O(n)` and we are using fixed array of 256 characters, so Space Compexity is `O(1)` .
